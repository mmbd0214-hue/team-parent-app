PWA 手機桌面安裝功能

新增：
- manifest.webmanifest
- service-worker.js
- Android / Chrome 安裝提示
- iPhone / iPad Safari「加入主畫面」說明
- standalone App 顯示模式
- App icon
- App 名稱：青山社區棒球隊家長 APP
- 桌面短名稱：青山棒球

家長使用：

Android：
1. 用 Chrome 開啟 Render 的球隊 App 網址
2. 我的 → 加到手機桌面
3. 按「安裝青山棒球 APP」

iPhone：
1. 用 Safari 開啟 Render 的球隊 App 網址
2. 分享
3. 加入主畫面

注意：
建議用 Render 原始 HTTPS 網址作為 PWA 安裝入口，不是 liff.line.me URL。
LIFF 連結仍然可以保留給 LINE 群組使用。
