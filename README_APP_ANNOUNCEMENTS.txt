LINE 發送 + App 公告同步

功能：
1. /admin → 訊息中心
2. 發送 LINE 訊息時，可填公告標題
3. 預設勾選「同步保留在家長 App 公告」
4. 同一則內容：
   - 當下透過 LINE 推送
   - 同時永久存進 announcements
5. 家長端新增「📢 公告」
6. 後來才加入的家長：
   - 全部家長公告：可看到歷史公告
   - 組別公告：只要目前綁定球員屬於該組別，就可看到歷史公告
   - 指定家長公告：只限原本指定家長
7. 後台可隱藏 / 重新顯示 / 刪除公告

資料庫自動新增：
announcements

注意：
LINE 已經發出的訊息無法因刪除 App 公告而收回。
